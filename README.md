## Scripts
- `rice.sh` - main install & setup script
- `sync_current_to_repo.sh` - copies all local changes form `~/.config`. The config folder must already exist in repo or the script will skip it - this avoids copying unwanted/default configs.
- `helpers.sh` - some share helper functions (log, paru install, etc.)
